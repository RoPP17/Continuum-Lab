# CONTINUUM LAB — Brand Identity & Visual Assets Suite

Esta carpeta contiene el sistema completo de identidad visual para **Continuum Lab**, basado en el perfil aerodinámico de flujo laminar (#4), optimizado con tipografía de precisión ingenieril (**Bahnschrift / DIN 1451**), estética obsidian cybernetic y en idioma inglés, sin saturación ni ruido visual.

---

## 📐 Especificaciones de Archivos y Usos

### 1. YouTube & Redes Sociales
| Archivo | Dimensiones | Uso Recomendado |
| :--- | :--- | :--- |
| `logo_avatar_youtube.png` | 1080 × 1080 px | **Foto de Perfil / Avatar (YouTube, TikTok, Instagram)**. Probado para máscara circular (zona de seguridad de 160 px de margen radial). |

### 2. Logotipos Horizontales (Lockup de Canal)
Ideal para intros de video 16:9, encabezados web, firmas, miniaturas de video y presentaciones.

* `logo_canal_horizontal.png` (2400 × 800 px): Fondo Obsidian Deep Navy (`#04060a`), isotipo con resplandor cian + `CONTINUUM LAB` + `COMPUTATIONAL PHYSICS`.
* `logo_canal_horizontal_transparente.png` (2400 × 800 px): Fondo transparente para sobreponer sobre simulaciones o fondos de video.
* `logo_canal_horizontal_minimal.png` (2400 × 800 px): Fondo Obsidian, isotipo + `CONTINUUM LAB` únicamente (cero subtítulos).
* `logo_canal_horizontal_minimal_transparente.png` (2400 × 800 px): Versión minimalista con fondo transparente.
* `logo_canal_horizontal_monocromatico_blanco.png` (2400 × 800 px): Isotipo y tipografía 100% blanca sobre fondo transparente (marca de agua).
* `logo_canal_horizontal.svg`: Archivo vectorial maestro escalable a cualquier resolución (4K/8K).
